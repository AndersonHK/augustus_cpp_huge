Public save/scenario loads checkpoint an existing world before mutation. On a late failure they discard the candidate and restore that checkpoint; cold failures discard the partial world. Resets clear terrain/navigation caches and scenario overrides before hydration. Navigation reset abandons any incomplete load scope, and derived-route reconstruction preserves serialized routing counters. This is synchronous checkpoint/rollback, not an independently allocated candidate-world object. Nonserialized UI state and remaining editor entry points still require audit.

This changes no authored scenario values. `out/rollback-cold3.log` verifies a byte-identical warm rollback, complete cold-failure cleanup, a subsequent clean load, and 3,000 rendered frames. Its stderr contains exactly the two deliberately induced model-payload rejection errors; the following load and soak emit none.
