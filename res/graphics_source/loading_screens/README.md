# Loading-screen artwork

Generated with the built-in image-generation tool on 2026-09-07. These are original generated illustrations, not extracted Caesar III or Augustus graphics.

- `first_concepts/` preserves the original completed-city concepts at the user's request.
- `construction/` contains the later construction stage, used while binding mod definitions.
- `extraction/` contains the earlier surveying, quarrying and foundation stage. `Vespasian-corrected.png` is the selected version; it removes an unintended completed amphitheatre in the background.
- `generation.json` preserves every prompt and original generation path.

The tool returned 1672 × 941 images despite requesting 3840 × 2160. These originals have not been represented as native 4K. The runtime scales and crops the selected backgrounds to cover the window.

Only selected runtime copies are shipped, under each mod's `UI/loading/`. Keep generation inputs and unselected concepts here.
