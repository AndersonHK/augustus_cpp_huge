# Launcher icon

`master.png` is the editable high-resolution RGBA master for `res/vespasian_launcher.ico`.

Generated with the ImageGen tool for this project on 2026-09-05, using the existing Vespasian game icon as a visual reference. Direction: a Roman bronze medallion, Vespasian portrait to the left, an arch and launch triangle to the right, gold and burgundy palette, no lettering, transparent background. A subsequent ImageGen edit removed the initially baked checkerboard and supplied actual alpha transparency.

The ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel representations. No Caesar 3 or extracted Augustus graphics were used in this icon.
