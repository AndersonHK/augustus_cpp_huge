# Comparative City-Builder Design Notes

Snapshot: 2026-05-10

These documents are weakly linked design references. They are intentionally
separate from the Caesar III / Julius / Augustus and Roman-history research.
Consult them only when a Vespasian proposal needs a design pattern from another
game. Do not use them as direct tuning inputs for Roman service ratios,
population class ratios, building areas, or maintenance burdens.

Use these for questions such as:

- How can employment demand regulate housing growth?
- How can class-specific workforce make upper classes useful without replacing
  lower classes?
- How can service capacity or popularity pressure make growth more legible?
- How can the game preserve lower-tier population after higher tiers unlock?

Do not use them to answer questions such as:

- How many baths should a Roman city have?
- How many patricians should exist in a provincial town?
- How many employees should a Roman library, fullery, or market require?
- How much land should a Roman elite house occupy?
